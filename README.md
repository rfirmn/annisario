# Hai Sayangkuu

Intro ulang tahun untuk Annisa. HTML, CSS, dan JavaScript tanpa build atau dependency.

Jalankan dari folder ini dengan `python3 -m http.server 4173 --directory dist`, lalu buka http://localhost:4173.

Tombol panah membuka surat setelah intro. Surat berisi pesan awal, pembuka puisi, tiga bait puisi di kertas krem, dan pesan penutup; tombol di akhir membuka outro. Tombol ulang mengulang intro. Gradasi pink dan biru dengan aksen hati, responsif di mobile, mendukung keyboard dan prefers-reduced-motion. Font disimpan lokal.
